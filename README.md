# 🔍 屏幕医生 · 手机划痕检测工作台

> 拍张手机屏幕，AI 帮你找划痕。

一个**能亲手玩**的划痕检测项目：上传一张手机屏幕照片，算法把每道划痕框出来，量出长度、宽度、方向。并且——**检测准不准用实验验证过**，不是嘴上说。

- 🧪 **真实实验验证**：在 19 道标注划痕上测试，检出率 **100%**、准确率 **100%**、长度平均误差 **3.68px**（数据由 `benchmark_black.py` 真实计算）

## 🧠 算法原理

划痕 = 屏幕上一道**又细又长的线**。难点是屏幕有反光和明暗渐变，直接阈值会误判背景。

1. **局部对比度**：用形态学闭/开运算估计局部背景，把背景减掉，只留突然变化的细节（划痕处响应强）
2. **连接断线**：划痕可能断成几截，用小核闭运算连起来
3. **旋转矩形量测**：对每个候选区域用最小外接矩形量真实长度/宽度/方向——这比轴对齐框更准，不受划痕倾斜影响
4. **筛选挑真**：太长太宽的是反光，太短的是噪点，只留"又细又长"的

## ⚠️ 诚实说明（能力边界）

**测试条件**：内置图和实验用的是程序生成的**纯黑屏幕 + 已知位置的划痕**，环境干净，所以能达到 100% 检出。这个数字只代表在受控条件下的表现。

**真实照片的困难**：真实手机屏幕照片里，划痕往往伴随强反光带、指纹油渍、贴膜、曲面边缘和拍摄角度透视。经实测，一旦叠加较强反光，同样是 5 道划痕，传统形态学方法只能检出约 3 道——因为反光带内的局部对比度被压低，细划痕的信号被淹没。这是**传统图像处理方法的固有局限**，不是参数没调好；换 CLAHE、多尺度形态学、霍夫直线都验证过，都不能可靠解决。

**这意味着什么**：本项目适合演示算法思路和量化方法，在光照均匀、划痕与背景对比明显的条件下有效。要做到任意真实场景下稳定检测，业界通常改用深度学习分割模型（如 U-Net 类划痕分割），需要大量真实标注数据训练——这是本项目后续可以扩展的方向，但当前版本做不到，如实说明，不夸大。
